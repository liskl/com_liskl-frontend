Old Commits, Kept for the Record

From the archives

A few of the oldest public repos on my GitHub, from 2016 to 2020. Some shipped, some are a README and good intentions. They are listed newest first, so the honesty improves as you scroll down.

  • Aug 2020
    • sops-action - a GitHub Action for decrypting SOPS secrets in CI. Started, never finished: the repo is a README and a license.
  • Dec 2019
    • blog-service - a REST blog API in Go 1.13, written to learn Go. Routing with gorilla/mux, GORM on MySQL or Postgres, JWT login and bcrypt-hashed passwords.
    • Controller and model tests read their database settings from environment variables, and a multi-stage Dockerfile builds it into a small Alpine image.
  • 2017
    • etcd-armv7l - etcd 3.2 built for a Raspberry Pi 3 (armv7l), packaged as a FROM scratch image with ETCD_UNSUPPORTED_ARCH=arm set, since etcd did not officially support ARM.
    • A single-node run, trimmed from the README: 
      docker run --rm --net=host liskl/etcd-armv7l:v3.2.0 \
    --data-dir /etcd-data \
    --listen-client-urls http://0.0.0.0:2379 \
    --advertise-client-urls http://0.0.0.0:2379
    • Later ARM experiments, ODROIDs this time, turn up on the homelab page.
  • 2016
    • docker-library_ - the Liskl Networks Docker Library, a monorepo holding Alpine base, Python Flask and Mosca (MQTT broker) images, built and tested on CircleCI.
    • A small helper script wraps git subtree so each image can be pushed back out to its own repo.
  • Sep 2016
    • docker-mosca - a Node.js MQTT 3.1 broker image on my own base image. The README is the whole repo; the actual image lives in the library above.
    • docker-flask - an Alpine base image for Flask apps. Same story: a README-only stub, with the real Dockerfile in the library.
    • docker-base - an early Alpine 3.2 base-image build config, and one of my first container repos.
