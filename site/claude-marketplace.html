Claude Code Plugin Marketplace

A Claude Code plugin marketplace with three plugins: metaskills for collaborative discovery, PRD creation and skill building, a software engineering audit, and a seedbox torrent controller.

Install

Add the marketplace, then install the plugin you want:

/plugin marketplace add liskl/claude-marketplace
/plugin install software-eng-laws@liskl-metaskills
/reload-plugins

Swap software-eng-laws for any plugin name below.

software-eng-laws

Audits a repository against 56 software engineering laws (Conway, Hyrum, DRY, CAP, etc.) and writes a per-law findings report with evidence citations and a scorecard. Run it with /software-eng-laws.

metaskills

Slash commands for collaborative discovery, PRD creation and skill building.

  • /metaskills:explore - light, conversational discovery for new projects or features that surfaces the questions experienced collaborators ask before jumping to implementation.
  • /metaskills:create-prd - turns rough or detailed ideas into a structured PRD, adapting its depth to the input, in Obsidian-optimized or plain markdown.
  • /metaskills:skill-builder - an interview-driven generator that pulls tacit knowledge from a domain expert and emits a Claude Code skill or slash command.

whatbox-rtorrent

Lists and controls torrents on a seedbox over rTorrent XML-RPC (list, start, stop, pause and resume), in stdlib-only Python 3.10+ with nothing to pip install.

The source is on GitHub at liskl/claude-marketplace.
