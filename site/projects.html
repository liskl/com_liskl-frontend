kind-local-test-suite

A one-command local Kubernetes test bed: a multi-node kind cluster whose Flux components are managed by the Flux Operator, with secrets kept SOPS-encrypted in git. It's for trying out GitOps changes locally, then recreating the cluster from scratch when it gets messy. This one lives in a private repo.

pre-commit-kustomize

A pre-commit hook that runs kustomize build inside a container running as a non-root user, so a broken overlay fails before it gets committed. github.com is added to the image's known_hosts, which lets overlays use remote refs. It started from an existing open-source kustomize image, and also bundles the KSOPS plugin for overlays that carry SOPS-encrypted secrets.

whoami

A tiny Go demo app that answers HTTP requests with the pod's hostname and serves Prometheus metrics on /metrics. Scale it to a few replicas, hit it a few times, and you can see whether load balancing is actually spreading the traffic.
